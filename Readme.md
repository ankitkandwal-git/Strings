Welcome to the String section of my DSA workspace! This directory contains a curated set of classic and challenging string problems, each with multiple language implementations. Explore, learn, and enhance your coding skills!

📂 Folders & Problems

1. Isomorphic String
	- Languages: C++ (main.cpp), Java (Main.java), Python (main.py)
	- Description: Check if two strings are isomorphic (one-to-one character mapping).
2. Largest Common Prefix
	- Languages: C++ (main.cpp), Java (Main.java)
	- Description: Find the longest common prefix among a set of strings.
3. Largest Odd Number
	- Languages: C++ (main.cpp)
	- Description: Find the largest odd number that can be formed from the string.
4. Reverse The String
	- Languages: C++ (main.cpp), Java (Main.java)
	- Description: Reverse the given string.
5. Integer To Roman
	- Languages: C++ (main.cpp)
	- Description: Convert an integer to its Roman numeral representation.
6. Max Nesting Depth Parenthesis
	- Languages: C++ (main.cpp)
	- Description: Find the maximum nesting depth of parentheses in a string.
7. Remove Outermost Parenthesis
	- Languages: C++ (main.cpp), Java (Main.java), Python (main.py)
	- Description: Remove the outermost parentheses from a valid parentheses string.
8. Roman To Integer
	- Languages: C++ (main.cpp), Java (Main.java)
	- Description: Convert a Roman numeral string to an integer.
9. String To Integer
	- Languages: C++ (main.cpp)
	- Description: Convert a string to an integer (similar to atoi).
10. Substring With K Distinct Characters
	- Languages: C++ (main.cpp, multiple approaches)
	- Description: Count substrings with exactly K distinct characters.
11. Valid Anagram
	- Languages: C++ (main.cpp), Java (Main.java)
	- Description: Check if two strings are anagrams of each other.
